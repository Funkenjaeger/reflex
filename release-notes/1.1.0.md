## reflex v1.1.0

The release where the controller stops trusting and starts verifying. Before
every pass it checks that the carriage really moved, and after every pass it
re-derives thread phase from the Z scale, so you can open the half nut between
passes. It is also the first release from one repository: firmware and UI are
one version, released together.

### ⚠ Upgrade notes
- **Firmware and UI move together** (register protocol 7). Flash the firmware
  from the same checkout as the UI, with the ST-Link, and power-cycle the
  controller afterwards. The UI checks the protocol when it connects and says
  which half is older if they disagree.
- **One repository.** The firmware (`fw/`) and the UI (`ui/`) now live here,
  with their history. Install from a clone of this repository, as in the
  guide's *Installing on a Pi*.
- **The in-app update screen is withdrawn** for this release: it pointed at the
  old repository and could only ever have updated the UI half. Update with
  `git pull` and, when the firmware moves, a flash.
- **Error reporting is off by default** and has no built-in destination. To use
  it, set `REFLEX_SENTRY_DSN` to your own and turn it on.

### What's new
- **Take-up confirmation:** before every pass the controller drives the
  leadscrew through its backlash and watches the Z scale. If the carriage did
  not move, the pass does not start (*"Cut aborted — is the half-nut
  engaged?"*).
- **Backlash calibration:** measure take-up on the machine instead of guessing
  it. ELS settings (gear on the ADV bar) → **Measure backlash**. It sets the
  servo mode it needs by itself, without arming sync.
- **Thread phase re-sync from the Z scale** after every pass, in every stop
  mode.
- **Pick up an existing thread:** latch a thread reference on work this job
  did not cut. ELS settings → **Pick up existing thread**.
- **Thread phase offset:** cut a groove wider than the tool by stepping phase
  between passes. ELS settings → **Thread phase offset**.
- **Status gutter** on the advanced bar: the thread reference
  (`NO REFERENCE` / `REF LATCHED`) and the phase offset, as two chips in a
  strip of their own.
- **A user guide**, from installing on a Pi through to picking up an existing
  thread: https://funkenjaeger.github.io/reflex/
- **Half the interrupt load:** step generation at 50 kHz instead of 100, and
  sustained ISR load down from 40% to 20%.

### Fixes
- Take-up warnings lead with **Cut aborted**, so the first thing you read is
  the state of the machine.
- Thread pick-up refuses in feed mode, and says why.
- A failed read from the controller is no longer taken as the value zero on
  the paths that steer the machine.
- A lathe no longer offers the pattern screen.
- The UI comes back after a clean exit, not only after a crash.
- Crash reports no longer go to the upstream project's account.

### Verified
Hardware-verified on the development lathe on 2026-08-30, in the configuration
it shipped in: backlash calibration came back within 3.3% of the commissioned
value, pitch measured correct, take-up confirmed, and the rest of the test
sheet passed. Built and published by the release workflow, after a green dry
run.

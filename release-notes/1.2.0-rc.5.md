## reflex v1.2.0-rc.5

Fixes from the first real in-app update and backup session on the lathe, a
readability pass over the touchscreen, and a new guard that refuses to save
settings on a machine that has never been commissioned. Same register
protocol as rc.4 (11); installing it from the touchscreen reflashes the
controller with the same firmware under a new version stamp.

### ⚠ Upgrade notes
- **A card that has never been commissioned now says so.** If the config
  directory holds fewer than 15 settings files or no ELS settings, the UI
  shows an **UNCOMMISSIONED** strip on the home screen and does not save
  settings, so defaults can never be recorded as this machine's calibration.
  Restore a backup, or tap the strip and dismiss it to commission by hand.
  A commissioned machine sees no change.
- **Updating from rc.4 still needs one tap on Exit Application** at the end
  (rc.4's updater cannot restart itself). Updates from rc.5 onward restart
  the UI by themselves.

### Fixes
- **In-app update:** the UI now restarts itself after an update; the
  pre-release choice is remembered; turning it on lists pre-releases
  immediately; the "do not power off" warning fits the screen; the status box
  scrolls into view when an update starts.
- **Gist backup:** automatic sync keeps working after a restart and no longer
  pauses the screen; restoring from a gist works (it could never list one);
  an expired GitHub sign-in turns sync off and says so, instead of retrying
  silently. Feed selections are no longer recorded as machine changes.
- **Readability:** dimmed text now meets 3:1 contrast in both themes; rows
  with no help page no longer show a dead "?" icon; popups are no longer
  darkened in the light theme.
- **Setup → System** shows free space only. The partition-resize and reboot
  buttons are gone (they could not work, and system administration does not
  belong in the operator UI).

### Known limitation
- The bootloader can lose sync with the serial link after a corrupted
  message. The updater recovers from this (it resumes the transfer, or puts
  the previous firmware back); a bootloader fix would need a programmer and
  is not part of this release.

### Verified
Firmware, UI and system CI green on the promoted commit. The fixes above were
exercised on the development lathe on 2026-09-19 (update, USB and gist
backup and restore); the commissioning guard and the restyled screens are
checked on the lathe as part of installing this release.

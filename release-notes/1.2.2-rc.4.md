## reflex v1.2.2-rc.4

The firmware's Modbus link and task structure are rebuilt: it now runs without
FreeRTOS, and the motion interrupt is no longer held back. The firmware also
disengages the ELS job itself on one command, and the UI leaves a running job
alone when it restarts. The register map changes (protocol 13), so the
firmware and the UI update together.

### Upgrade notes
- **From 1.2.2-rc.3: Setup → Update**, with **Offer pre-releases
  (experimental)** on. The firmware half is re-flashed (protocol 12 to 13).
- Nothing to re-measure. The backlash calibration, the gearbox table and the
  overshoot table carry over.

### What's new
- **Disengage is one command.** The firmware turns sync off, stops the feed
  and ends the job, in that order, and then confirms. If no confirmation
  arrives within about a second, the UI sends the command again. If that is
  not confirmed either, the status bar says "The controller did not confirm
  the disengage."
- **A UI restart no longer stops work in progress.** If the UI starts while
  the carriage is feeding, moving, taking up or calibrating, it leaves the job
  running, stop included, and shows a notice. A job that was only holding is
  disengaged, as before.
- **Measure the gearbox factor.** In **Advanced ELS settings**, press
  **Measure** on the **Measure gearbox factor** row, choose the lever
  position, and run three passes in air. The factor is read over each whole
  pass and offered for **Save** or **Discard**. During the passes, take-up
  and retract use that position's factor.
- **Reinstall firmware.** When the selected release matches the installed UI
  but the controller runs other firmware, such as a diagnostic build, the
  **Update** screen offers **Reinstall firmware**. It re-flashes the
  firmware only.
- **New firmware core.** Modbus now runs on the same code as the bootloader,
  with DMA receive, and FreeRTOS is gone. The motion interrupt runs at the
  highest priority: on the development lathe it ran one tick late in four
  minutes, where before it ran thousands of ticks late a minute. The firmware
  image is about 25 KB, down from 45 KB. The controller refuses host writes to
  firmware-owned registers, except the documented counter resets.

### Fixes
- **Backlash calibration waits for the drive.** It now starts moving about
  1.5 s after the drive is enabled. Before, the drive could miss the first
  steps, so a calibration right after a job could read wrong or say "Carriage
  did not move" with the half nut closed.
- **A failed backlash calibration no longer lowers the take-up check.** Only
  a run you **Accept** changes it. A run that fails, is aborted, or ends with
  **Discard** leaves the check as it was.
- After a discarded calibration, the servo is turned off cleanly; before, the
  controller could keep it on while the UI showed it off.
- The home screen draws correctly when the UI starts while the carriage is
  moving.
- An install or reinstall is written to the SD card before the screen says it
  is done, so a power cut right after it cannot undo it.

### Documentation
- The bundled LGPL Modbus library is removed; the firmware's Modbus code is
  the project's own.

## reflex v1.2.2-rc.4

The firmware now disengages the ELS job itself, on one command from the UI,
and a failed backlash calibration no longer weakens the take-up check. Both
change the register map (protocol 13), so the firmware and the UI update
together.

### Upgrade notes
- **From 1.2.2-rc.3: Setup → Update**, with **Offer pre-releases
  (experimental)** on. The firmware half is re-flashed (protocol 12 to 13).

### What's new
- **Disengage is one command.** The firmware turns sync off on every scale,
  stops the feed and ends the job, in that order, and then confirms. The UI
  waits for that confirmation. If none arrives within about a second, the UI
  sends the command again, and if that is not confirmed either, the status
  bar shows "The controller did not confirm the disengage." A connection that
  comes back before the confirmation sends the command again.

### Fixes
- **A failed backlash calibration no longer lowers the take-up check.** The
  check now keeps its own copy of the accepted calibration, and only a run
  you **Accept** changes it. A run that fails, is aborted, or ends with
  **Discard** leaves the check as it was.

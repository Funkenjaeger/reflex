## reflex v1.2.2

The ELS now checks the carriage against what it commanded, and each machine
measures its own stop overshoot. The firmware core is rebuilt without FreeRTOS,
so the motion interrupt is no longer held back. Every update saves the
machine's settings first.

### Upgrade notes
- **From 1.2.1: Setup → Update.** The firmware half is re-flashed: the
  register protocol moves from 11 to 13, so the firmware and the UI update
  together.
- **Stop overshoot correction** (still off by default) now uses this machine's
  own table. A machine that had it on keeps the old built-in table only at the
  geometry it was measured under (200 counts/mm, 8 TPI, 1600 steps per
  revolution). Anywhere else the correction turns off with a notice. To
  measure a table, open **Advanced ELS settings**, **Overshoot table**,
  **Measure**, then **Sweep**. Measure one even where the built-in table
  stays on: the new firmware core coasts less at speed, so the old table
  stops short.
- **New settings start safe**: no gearbox table, and the coupling check only
  logs until **Coupling check acts (off = log only)** is turned on.
- **Disable Error Reporting** is now **Error reporting**: on means reports are
  sent. The stored setting is unchanged.

### What's new
- **Coupling check.** During a cut the ELS compares the carriage's motion with
  what it commanded. A half nut that is not engaged, or a rate that fits no
  gear, stops the pass with a red strip. A gearbox lever clearly in another
  position is named in a yellow strip and adopted on the next Cut.
- **Gearbox table and factor measurement**, for a lathe with a multi-speed
  gearbox between the servo and the leadscrew; without one, leave the table
  empty and none of this applies. Enter the gearbox positions in
  **Advanced ELS settings**; the main ELS screen shows the active one.
  **Measure gearbox factor** reads a position's factor over three passes in
  air. A gearbox change clears the thread reference, and every clear is shown
  on the ELS bar.
- **Stop-overshoot measurement.** **Detect** finds whether the carriage coasts
  past the stop. **Sweep** makes three passes at each of four speeds, in any
  order, labels each speed with its feed and spindle rpm, and fits a table to
  them. The table is bound to the machine: a change to the Z scale, the
  leadscrew or the gearbox table turns the correction off with a notice that
  names the change.
- **Disengage is one command**, confirmed by the controller and sent again if
  it is not. A UI restart leaves a running job alone.
- **New firmware core.** Modbus runs on the bootloader's code with DMA
  receive, and FreeRTOS is gone. Its critical sections masked the motion
  interrupt, so steps could run late, and the firmware's three periodic jobs
  need no scheduler: a plain main loop runs them. On the development lathe the motion
  interrupt ran one tick late in four minutes, where before it ran thousands
  of ticks late a minute. The image is about 25 KB, down from 45 KB.
- **Settings snapshot before each update**, named on the Update screen, so a
  setting an older release resets can be put back.
- **Reinstall firmware** on the Update screen when the controller runs other
  firmware than the installed release.
- **Plain language.** Faults and refusals say why on screen, in short
  sentences, with one thing to do. **Advanced ELS settings** replaces ELS
  Threading Settings and also opens from Setup.

### Fixes
- Backlash calibration waits about 1.5 s for the drive after enabling it, and
  only a run you **Accept** changes the take-up check.
- Retract waits for Sync Enable, like Cut, and a cut waits for its stop to be
  confirmed before the carriage moves.
- The overshoot notice appears only when the carriage stays above the table
  for a full second.
- An install is written to the SD card before the screen says it is done.
- Controller traffic no longer runs on the screen's thread, and the link no
  longer resets while the screen starts.

### Documentation
- Guides for measuring stop overshoot and the gearbox factor, and help pages
  that match the screens.
- The bundled LGPL Modbus library is removed; the firmware's Modbus code is
  the project's own.
- Per-candidate notes: `release-notes/1.2.2-rc.1.md` to `1.2.2-rc.5.md`.

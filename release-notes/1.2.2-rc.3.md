## reflex v1.2.2-rc.3

Each machine now measures and keeps its own stop-overshoot table, and a
gearbox change clears the thread reference. The firmware adds a command to
clear that reference (register protocol 12), so the firmware and the UI update
together.

### Upgrade notes
- **From 1.2.2-rc.2: Setup → Update**, with **Offer pre-releases
  (experimental)** on. The firmware half is re-flashed (protocol 11 → 12).
- **Stop overshoot correction** now uses this machine's own table. A machine
  that had it on keeps the old built-in table only at the geometry it was
  measured under (200 counts/mm, 8 TPI, 1600 steps per revolution). Anywhere
  else the correction turns off with a notice. To measure a table, open
  **Advanced ELS settings** and press **Measure** on the **Overshoot table**
  row.
- **Disable Error Reporting** is now **Error reporting**: on means reports
  are sent. The stored setting is unchanged.

### What's new
- **Stop-overshoot measurement.** The **Measure stop overshoot** window runs
  air passes in Feed mode. **Detect** finds whether the carriage coasts past
  the stop, and **Sweep** runs 3 passes at each of 4 feeds and fits a table to
  them. Then press **Save** or **Discard**. Cues on the ELS bar say what to do
  next, and the window links a step-by-step guide as text and a QR code.
- **The table stays bound to the machine.** A change to the Z scale
  resolution, the leadscrew or the gearbox table makes it stale. The
  correction then turns off with a notice that names the change, and the
  table is kept. A corrected stop that lands more than 1 count past its
  target also turns the correction off.
- **A gearbox change clears the thread reference**, so the next pass
  re-latches it in the new position. Every clear shows on the ELS bar, from
  any cause: "Thread reference cleared. The next pass re-latches it."
- **The coupling check starts sooner in Thread mode.** It now starts when the
  take-up ends, not about 0.4 s into the pass.
- **Plain-language text** on the ELS bar, in dialogs and popups and on the
  Update screen. Labels are in sentence case, and the re-sync wizard's Abort
  buttons now read **Cancel**.

### Fixes
- When the Measure window refuses **Detect**, **Sweep** or **Save**, it now
  shows the reason. Before, the reason appeared on the status bar behind it.
- Confirming an empty keypad field leaves the keypad open and logs nothing.
- The board's user LED is driven by one task only: a healthy board blinks
  500 ms on, 500 ms off.

### Documentation
- New guide: [Measuring stop overshoot](https://funkenjaeger.github.io/reflex/guide/measuring-stop-overshoot/).
- The help pages now match the screens, in Simplified Technical English.
- The README's feature list, roadmap and demo video are back.
- The bundled Modbus library is marked LGPL-2.1, and its license text is
  shipped.

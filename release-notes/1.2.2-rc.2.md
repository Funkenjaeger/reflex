## reflex v1.2.2-rc.2

The ELS now checks the half nut and the gearbox lever against how the carriage
actually moves, says why on screen when it stops, and no longer runs controller
traffic on the screen's thread. The firmware changes one Modbus timing constant
(register protocol 11, unchanged).

### Upgrade notes
- **From 1.2.2-rc.1: Setup → Update**, with **Offer pre-releases** on. The
  firmware half is re-flashed (the timing change). Existing settings carry over;
  the new ones start as no gearbox and the coupling check logging only.

### What's new
- **Coupling check.** During a cut the ELS compares the carriage's motion with
  what it commanded. A half nut that is not engaged, or a carriage rate that
  fits no gear, stops the pass with a red strip; a lever clearly in another
  position is named in a yellow strip and adopted on the next Cut. It stops
  passes only with **Coupling check acts (off = log only)** turned on in
  **Advanced ELS Settings**.
- **Gearbox table** in Advanced ELS Settings: none by default. With one, the
  main ELS screen shows the active position. The docs use the development
  lathe's gearbox, `A=1, B=2, C=1/2`, as their example.
- **ELS faults say why** in a red strip, with **Disengage** as the way out.
- **Refusals are short, plain sentences**: what is wrong, then one thing to do.
- **Retract waits for Sync Enable**, like Cut.
- **A cut waits for its stop to be confirmed** before the carriage moves, and
  the screen stays responsive while it does.
- **Advanced ELS Settings** is the new name for ELS Threading Settings, and it
  also opens from Setup.

### Fixes
- The controller link no longer resets while the screen starts up.
- A negative **Stop Z** or **Start Z** fits its value box.
- The network screen's State row reads in full.

### Documentation
- A help page for the gearbox table and the coupling check.
- The README screenshots were regenerated from a commissioned machine.

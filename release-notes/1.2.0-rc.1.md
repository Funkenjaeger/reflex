## reflex v1.2.0-rc.1

The first release with a field bootloader. Once it is on the controller,
firmware goes over the RS-485 link the UI already uses, with no ST-Link and no
power cycle. Also a flight recorder that keeps what the UI reads from the
controller, a safe diameter for stop + retract, and fixes from the bench.
Firmware and UI must be updated together.

### ⚠ Upgrade notes
- **Firmware and UI move together** (register protocol 9, up from 7 in 1.1.0).
- **The bootloader goes on once, with the ST-Link.** It takes the first flash
  sector and the application moves behind it, to `0x08020000`. Follow the
  bring-up procedure in `fw/bootloader/README.md`: program
  `reflex-bl-1.2.0-rc.1.elf`, then `reflex-app-1.2.0-rc.1.bin` into the RUN
  slot, then power-cycle. From then on, `fw/scripts/modbus-flash.py` flashes a
  `reflex-app-*.bin` over RS-485, with the UI stopped.
- **`reflex-fw-1.2.0-rc.1` is the legacy image**, for a board without the
  bootloader, flashed with the ST-Link as before. It cannot be flashed over
  RS-485.
- **The touchscreen Update screen is still withdrawn** in this release.
- **The flight recorder writes to the card:** at most 512 MB, oldest files
  deleted first, and it stops recording when less than 128 MB is free.

### What's new
- **Field bootloader** and `modbus-flash.py`: the application is staged,
  verified and applied, the previous one is kept as a backup, and a new image
  that never comes up is swapped back automatically.
- **Flight recorder:** the UI keeps the stream it polls from the controller
  instead of discarding it, so a pass can be examined after the fact.
- **Stop trigger snapshot:** the controller records the Z position and speed at
  the instant the stop fires. It is the measurement a correction for the
  carriage coasting past the stop needs.
- **Safe diameter for stop + retract:** a committed **Safe ø** now gates
  **Retract** until the tool is clear in X, as the wizard's **Major ø** already
  did. On by default. Turn it off in ELS settings → **Safe diameter**.
- **X DRO reads Radius / Diameter:** an explicit setting in Setup → ELS for
  how the cross slide reads.
- **Scale entry by resolution:** Setup → Inputs → **Scale entry** takes the
  number on the scale's sticker (microns per count), or the ratio as before.
  Every field says its units.

### Fixes
- Turning **Sync Enable** off mid-cut now ends the cut and frees **Disengage**,
  instead of leaving the machine engaged with no way out.
- **ADV** refuses to hide the advanced bar while a stop job is engaged, and
  says so.
- If the servo mode the controller reports disagrees with what the UI
  commanded, the operator is now told, not just the log.
- **Pick up existing thread** refuses before you move the machine, not after,
  when it cannot run.
- The thread reference is cleared when the servo drive is de-energized: the
  controller no longer knows where the leadscrew is.
- The spindle encoder's noise filter, meant to stop VFD noise counting as
  spindle motion, now takes effect. In 1.1.0 it was reset to zero at
  start-up.
- Rotary-table wording no longer appears on a lathe.

### Verified
Field flashing hardware-verified on the development lathe on 2026-09-07:
44,868 bytes over RS-485 in 12.9 s, and 664 frames across three runs with none
lost. CI green on the promoted commit.

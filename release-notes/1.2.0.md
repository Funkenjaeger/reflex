## reflex v1.2.0

The release where the machine updates itself from the touchscreen, and its
calibration survives a dead SD card. Firmware and UI install together over the
RS-485 link, through a field bootloader, checked and put back if anything
fails. Commissioning settings are recorded, backed up to USB or a GitHub gist,
and restorable. Experimental: stop overshoot correction, off by default.

### ⚠ Upgrade notes
- **From 1.1.0 this is a one-time bench job.** 1.1.0 has no in-app updater,
  and the register protocol moves from 7 to 11. Program the field bootloader
  and this firmware over SWD once (`fw/scripts/provision.sh`, see
  `fw/bootloader/README.md`), and update the UI checkout. Every update after
  that is from the touchscreen: Setup → Update.
- **A card that was never commissioned says so.** Fewer than 15 settings files,
  or no ELS settings, shows an **UNCOMMISSIONED** strip and saves nothing until
  a backup is restored or the warning is dismissed. A commissioned machine sees
  no change.

### What's new
- **In-app update, firmware and UI together:** protocol-checked, the previous
  firmware put back if a step fails, and it offers to disengage an engaged ELS
  job first. If the controller cannot be reached after a failed transfer, turn
  the machine off, wait 10 seconds and turn it on.
- **Field bootloader:** firmware goes over the RS-485 link, with no ST-Link
  after the first install. It runs on the board's crystal (the internal
  oscillator measured 3.6% slow and stalled transfers).
- **Backup and restore:** every commissioning change recorded on the card;
  export to USB or sync to your own GitHub gist, and restore from either.
- **Commissioning guard:** the UNCOMMISSIONED strip, above.
- **Generated register map:** one schema for firmware and UI, with a protocol
  fingerprint; the controller is read at about 28 Hz, up from about 16.
- **Flight recorder:** the poll stream and each stop's trigger instant kept on
  the card, so a stop can be examined afterwards.
- **Readability:** dimmed text meets 3:1 contrast in both themes; versions read
  as their release tags.
- X DRO in radius or diameter, scales entered as a resolution, and other
  operator fixes.
- **Stop overshoot correction** (*experimental, off by default*): latency in
  the servo drive keeps the carriage driven for a moment after the stop fires,
  so it lands past the target. This fires the stop early by the measured
  overshoot. Calibrated on one lathe only.

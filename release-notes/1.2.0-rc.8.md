## reflex v1.2.0-rc.8

Versions now read the way releases are named, and the documentation catches
up with what 1.2.0 is. The status bar and the Update screen show
v1.2.0-rc.8 instead of v1.2.0rc8*, on one line. The README and the user
guide describe the in-app update, backup and restore, the commissioning guard
and stop coast correction. Same register protocol (11).

### Fixes
- **Version display:** the status bar shows the release tag and shrinks the
  text to fit its box instead of wrapping onto two lines. The "*" it added for
  an editable install is gone; every machine installed from a checkout is
  editable, so it marked nothing.
- **Update screen:** **Install Selected Release** is greyed out when the
  selected release is the one already installed. For pre-releases the check
  compared two spellings of the same version and never matched.
- **Update help:** describes what the updater does now. It puts the previous
  firmware back when the two halves of a release disagree. It also covers the
  ELS disengage prompt and the power-cycle recovery.

### Documentation
- README versions: 1.2.0 listed as what it contains; auto-start moves to
  1.3.0, where it was always going to land unbuilt otherwise.
- New guide pages: Updating Reflex, Backing up your settings, The
  UNCOMMISSIONED strip, and Stop coast correction (experimental).
- Release notes written for 1.1.0 and 1.2.0-rc.1 through rc.3, which went out
  with none.

### Verified
Firmware, UI and system CI green on the promoted commit. The version display
was checked in the real app at 1024x600; installing this release from the
touchscreen is its final check, and the status bar should read v1.2.0-rc.8.

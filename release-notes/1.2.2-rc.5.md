## reflex v1.2.2-rc.5

The overshoot sweep now takes its four speeds in any order and can leave a speed
half done and come back to it. This candidate also adds a guide page and
quiets a notice that fired on a brief burst of speed. The UI changes; the
firmware does not, so the register map stays at protocol 13.

### Upgrade notes
- **From 1.2.2-rc.4: Setup → Update**, with **Offer pre-releases
  (experimental)** on.
- **Measure the overshoot table again** if it was measured before rc.4. The
  rc.4 firmware core changed when the stop fires. On the development lathe the
  fastest point's coast dropped from 27–28 counts to 22, so an older table
  stops a little shorter than it needs to.

### What's new
- **The overshoot sweep groups passes by speed.** In **Overshoot table**,
  press **Measure**, then **Sweep**, and make three passes at each of four
  speeds, in any order. Each pass joins the speed it matches within 10 %.
  Each speed is labeled with the feed on the ELS bar and the spindle rpm,
  for example "0.020 @ 340 rpm: 2/3 · 3 speeds left", so a speed left part
  way through can be found again. Touch the strip to open **Measure**, which shows the
  count for every speed. The guide suggests settings; the sweep no longer
  asks for the slowest first.

### Fixes
- **The above-range notice waits for a sustained speed.** "Z rate is above
  the calibrated range" now appears only when the carriage stays faster than
  the table's top point for a full second. A short burst, such as a thread
  pass catching up to the spindle just after **Cut**, still raises the
  correction to its largest value but no longer shows the notice.

### Documentation
- New guide page: measuring the gearbox factor.
- The overshoot guide says to make the fastest test speed faster than the
  fastest thread pass.
- The refusal catalog in the docs is generated with the screen's names
  ("Advanced ELS settings"), and CI checks that it is current.

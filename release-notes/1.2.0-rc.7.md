## reflex v1.2.0-rc.7

Updating with an ELS job engaged no longer just fails. The controller refuses
to reboot while a job is engaged, so the Update screen now offers to disengage
it for you and says why. Everything in rc.6 is included. Same register protocol
(11).

### ⚠ Upgrade notes
- **Installing this from rc.5 or rc.6:** if an ELS job is engaged, tap
  **Disengage** on the ADV bar first. Those updaters do not have the offer yet;
  from rc.7 onward the Update screen asks for you.

### Fixes
- **Update screen:** with an ELS job engaged, **Install Selected Release** asks
  "Disengage ELS and install?" and starts the update only once the controller
  confirms the job is released. If the spindle is turning, or a cycle is
  running, it says so instead.
- **Updater:** if the controller refuses to reboot, the status box says it was
  because an ELS job is engaged, instead of a timeout.
- **ADV bar:** Disengage now refuses during a running cycle in code as well as
  on screen (the button was already greyed out).

### Verified
Firmware, UI and system CI green on the promoted commit. Found on the
development lathe on 2026-09-25, when the rc.6 install failed safely under an
engaged job; installing this release from the touchscreen is its final check.

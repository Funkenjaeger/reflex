## reflex v1.2.1

A new card's first minutes, fixed. The UNCOMMISSIONED dialog now leads with
setting up a new machine, restores a backup in one tap, and the app restarts
itself to load it.

### Upgrade notes
- **From 1.2.0: Setup → Update.** The firmware is unchanged (register
  protocol 11).

### What's new
- **UNCOMMISSIONED dialog:** two lines and four buttons that fit the 1024x600
  screen: **New machine — set it up**, **Restore from USB stick**, **Restore
  from GitHub gist**, **Not now**.
- **Gist restore on a new card** signs in to GitHub first and turns nothing
  else on. It used to go through the sync toggle, which uploaded the card's
  defaults as a new gist that then sat above the real backup in the list.
- **After an import** the app counts down 10 seconds and restarts itself to
  load the restored settings.
- **Stop overshoot correction help** corrected: its table depends on the
  drive, the scale resolution and the gearing, not on the servo speed and
  acceleration settings.

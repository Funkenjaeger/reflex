## reflex v1.2.2-rc.1

Every update now saves the machine's settings first, so a setting can be put
back by hand if an older release resets it. The firmware is unchanged
(register protocol 11).

### Upgrade notes
- **From 1.2.1: Setup → Update**, with **Offer pre-releases** on. The firmware
  half is rebuilt but has no functional change.

### What's new
- **Settings snapshot before each update.** The Update Status box names the
  file it wrote, in the commissioning snapshots. An older release does not know
  settings that a newer one added and resets them to their defaults the first
  time it saves, so this snapshot is how to recover one.
- **Integration build source (development benches only).** A machine can be
  pointed at a second, private release source; the Update screen then shows an
  **Offer integration builds** row. On any other machine nothing changes and
  the row does not appear.

### Documentation
- The design decisions are one page on the docs site, and the design and
  reference docs were cut to what a reader can use.
- Timing prose and comments now give the motion ISR's real 50 kHz rate.
